How it works

  1. Drop a document into Paperless (upload, consume folder, mail). Paperless reads it and adds the tag sortieren.
  2. Open Doc Sorter: the document is in the queue. Generate suggestions, tick what fits, change the rest, click Apply.
  3. Already-stored documents: in Paperless select them → Tags → add sortieren. They show up in the queue too.
  4. Bad scan? Add ki-ocr – the vision model reads it again (only if set under Advanced).

Tip: if you made a Paperless workflow with “Apply AI Suggestions”, switch it off, so documents aren't sorted twice. Prompts (e.g. “use only these tags …”) can be tuned in the sorter under Settings.
